A tiny stack virtual machine in one file, built for make.fun's
["Build a tiny stack virtual machine"](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty.

It runs every instance under `/input/<id>/` (`program.bin` + `input.bin`)
and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt`.

Run it with Node 22:

```
node main.ts
```
